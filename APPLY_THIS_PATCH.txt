Kathanika V30 GitHub Pages case-path hotfix

Cause fixed:
GitHub Pages publishes this repository at /Kathanika/ (capital K), while the previous V30 build emitted asset URLs under /kathanika/ (lowercase k). GitHub Pages static paths are case-sensitive, so CSS, JavaScript, images and thumbnails returned 404 and the browser displayed unstyled HTML.

Copy all files in this patch over the existing kathanika-media-v30-production folder, replacing files when asked.
Then run:
  npm run verify
  npm run preflight:pages
  npm run git:preflight
  git add .
  git commit -m "Fix GitHub Pages case-sensitive asset path"
  git push origin main

Wait for the GitHub Pages Action to finish, then hard-refresh:
  https://amoghchowdary.github.io/Kathanika/
