KATHANIKA MEDIA — GOOGLE INDEXING STEPS

Technical SEO included in V50:
- Page-specific titles and descriptions
- Canonical URLs
- Open Graph / Twitter preview metadata
- Organization JSON-LD structured data
- Social identity links (YouTube, Instagram, LinkedIn)
- sitemap.xml (Google-supported sitemap)
- sitemap.yml (human-readable manifest only)
- robots.txt with sitemap reference
- 1200x630 Open Graph image
- Image alt text and visible production context

IMPORTANT:
Google Search does not use YAML as the sitemap format. sitemap.xml is the file to submit.

After the V50 site is live:
1. Open Google Search Console.
2. Add/verify the live Kathanika website property.
3. Open Sitemaps and submit the live sitemap.xml URL.
4. Use URL Inspection for the homepage and major pages.
5. Run Test Live URL, then Request Indexing.
6. Monitor Page Indexing and Video Pages reports.
