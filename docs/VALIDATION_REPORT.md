# Kathanika Media V70 — Validation Report

V70 carries forward the production website and V69 native Courses work, then adds two backend-linked inquiry flows:

- visible Career Inquiry form on the Careers page;
- visible Course Inquiry form on `/courses`;
- Apps Script API V31 routing for `careerInquiry` and `courseInquiry`;
- dedicated `Career_Inquiries_V70` and `Course_Inquiries` database tables;
- brochure/poster assets remain excluded from production.

Use `npm run verify` and `npm run preflight:pages` for the complete production validation suite.
